# Shottr

A fast, minimal screenshot tool for Windows, inspired by Greenshot. Capture a region, a
window or the whole screen, mark it up, then copy or save it.

## Using it

Shottr lives in the notification area. Captures open straight into the editor.

| Shortcut | Action |
| --- | --- |
| Print Screen | Capture a region. Drag to select, or click a window to capture it. Esc cancels. |
| Alt + Print Screen | Capture the active window |
| Ctrl + Print Screen | Capture the full screen (the monitor under the mouse, or all monitors) |

You can change these shortcuts in Settings. If Windows opens Snipping Tool when you press
Print Screen, the Settings window has a button that hands the key to Shottr.

### Editor

| Key | Tool or command |
| --- | --- |
| V | Select and move |
| R | Rectangle (Shift for a square) |
| E | Ellipse (Shift for a circle) |
| A | Arrow (Shift snaps to 15°) |
| T | Text: plain, label or speech bubble. Click to place it, then type or paste. |
| N | Numbered counter bubble with adjustable size |
| O | Obfuscate: pixelate or blur, with an amount slider |
| Ctrl+C / Ctrl+S / Ctrl+Shift+S | Copy / save to the captures folder / save as |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Delete, arrow keys | Delete or nudge the selected markup (Shift+arrow moves 10 px) |
| Ctrl+wheel, Ctrl+0, Ctrl+1 | Zoom, fit, actual size |
| Esc | Deselect, or close the editor when nothing is selected |

The options bar under the header shows only the settings for the active tool. Shottr
remembers the last options you used for each tool.

## Building

Requires the .NET 10 SDK on Windows.

```
dotnet build Shottr.sln
dotnet run --project src/Shottr
```

To install a portable copy, run `.\publish.ps1`. It builds a single `Shottr.exe` and copies it
to `%LOCALAPPDATA%\Programs\Shottr`. Then tick "Start Shottr when I sign in to Windows" in
Settings. The script also accepts `-Destination <folder>`, `-StartMenuShortcut`, `-Launch`,
`-FrameworkDependent` (a small exe that needs the .NET 10 Desktop Runtime) and `-NoInstall`
(build only). Rerunning it updates the installed copy and keeps the startup entry pointed at it.

Command-line switches: `--region`, `--fullscreen`, `--settings` and `--open <image>`.
Setting the environment variable `SHOTTR_SOFTWARE=1` turns off GPU rendering, which helps
on machines or remote sessions where WPF windows show up blank.

The app icon is generated by `tools/IconGen`:

```
dotnet run --project tools/IconGen -- src/Shottr/Assets
```

## Notes

If Windows Security's *Controlled folder access* is on, Windows blocks Shottr from saving
into Pictures until you allow it under Windows Security > Ransomware protection > Allow an
app through Controlled folder access. You can also pick another captures folder in Settings.
